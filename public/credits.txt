PUBLIC CATALOG METADATA

Wikidata structured data is available under CC0.
https://www.wikidata.org/wiki/Wikidata:Data_access
Records retain their Wikidata entity links. Discovery uses a conservative direct
video-game classification and is not an exhaustive census.

Game data from FreeToGame:
https://www.freetogame.com/
https://www.freetogame.com/api-doc
The API documentation permits personal/commercial use with an active attribution
link and asks clients to avoid more than 10 requests per second. The app uses the
documented metadata API, not a scrape of the website. Its general website terms
still apply: https://www.freetogame.com/terms-of-use
FreeToGame is not CC0. Its data covers its free-to-play catalog, not all paid games.
No external artwork, descriptions or critic scores are copied into these records.

Catalog lookup sends only the public query/source/page to a stateless same-origin
proxy and the chosen provider. Private library state is never sent to that proxy.
Source failures, rate limits and unavailable metadata are shown explicitly.
